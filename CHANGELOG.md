# Changelog

## 0.1.0a1 — GitHub exploratory prerelease, 2026-09-12

- Strict CSV/TSV column adapters through a JSON manifest for four upstream result modalities.
- Offline, versioned mouse reference: seven selected PPP reactions, exact identifiers and explicit alias candidates.
- Original values, P values, contexts, source records and SHA256 provenance retained.
- Entity ambiguity separated from multiple reaction participation; duplicates and unknown/excluded context retained for review.
- Searchable HTML ledger, reaction view, JSON/TSV/SVG exports and output hashes.
- Synthetic examples, validation tests and wheel/sdist installation checks.

[GitHub prerelease](https://github.com/guatou904/pathwaybridge/releases/tag/v0.1.0a1) is published and the downloaded wheel and sdist pass clean installation. Independent mapping review, comparative user trials and PyPI publication remain pending.
