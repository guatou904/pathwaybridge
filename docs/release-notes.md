PathwayBridge is an exploratory, offline evidence ledger for seven selected mouse PPP reactions. It maps upstream bulk RNA, single-cell, spatial and metabolite result tables while retaining original values, context, mapping ambiguity and source-row provenance.

This prerelease is not a complete PPP database and does not estimate activity or flux. Independent scientific review and comparative user validation remain pending. Read the input contract and mapping policy before using it for a study.

Install the attached wheel or source distribution in a fresh Python 3.11+ environment. Run `pathwaybridge demo --out demo-run` and open `demo-run/report/report.html`. The packaged example is synthetic. `INSTALL_VALIDATION.json` and `SHA256SUMS` record the artifacts checked in the publication workflow. The attached standalone HTML demonstrates the report; use the packaged demo for its companion JSON/TSV exports.
