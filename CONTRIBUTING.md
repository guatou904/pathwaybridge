# Contributing

Keep the first release bounded to result-table evidence, a mouse PPP reference and offline outputs. Start from a reproducible input-contract or mapping problem. Do not submit private study values, raw patient/sample identifiers or unpublished figures; construct a synthetic counterexample.

For a mapping change, include the primary source URL, database release/entry version, supported species/namespace, exact chemical identity, reaction roles, all alternative candidates and the source evidence class. Update the mapping version and add a regression case. A synonym that looks obvious can refer to a different gene or chemical form.

Run the commands in README. Do not update fixtures simply to make tests pass. Record which checks were actually executed. Independent scientific review and user validation are distinct from automated tests.

Deletion policy: no bulk file/directory deletion. When a generated directory is in the way, choose a new output path; do not use recursive removal commands. Keep local data and artifacts out of commits and packages.
